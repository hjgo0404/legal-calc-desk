# 법무 계산 데스크

법정기간 마감일, 소송비용, 가사·상속 계산기를 한 페이지에 모은 정적 웹사이트입니다.
서버·DB 없이 HTML/CSS/JS만으로 동작하고, 입력값은 각 사용자의 브라우저 밖으로 나가지 않습니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면 구조 |
| `css/style.css` | 디자인 (라이트·다크 모드) |
| `js/app.js` | 계산 로직 · 공휴일 표(2025~2027) · 절차 목록 |
| `manifest.webmanifest`, `sw.js` | 휴대폰 홈 화면 설치 · 오프라인 동작 |
| `icons/` | 파비콘, 앱 아이콘, 카톡 공유 미리보기 이미지(`og.png`) |

## 인터넷에 올리기 (무료)

### 방법 1. Netlify Drop — 가장 쉬움 (5분)
1. https://app.netlify.com/drop 접속 (무료 가입)
2. 이 폴더(`legal-calc-desk`) 통째로 끌어다 놓기
3. `https://임의이름.netlify.app` 주소가 바로 생김 → Site settings에서 이름 변경 가능
4. 수정할 때는 Deploys 탭에 폴더를 다시 끌어다 놓기

### 방법 2. GitHub Pages
1. GitHub에 새 저장소를 만들고 이 폴더의 파일을 올림
2. 저장소 Settings → Pages → Branch: `main` / `(root)` → Save
3. 1~2분 뒤 `https://아이디.github.io/저장소이름/` 에서 열림

### 방법 3. 내 컴퓨터에서만 보기
`index.html`을 더블클릭하면 브라우저에서 바로 열립니다 (오프라인 설치 기능만 빠짐).

## 자주 고칠 곳

- **공휴일 추가(2028년 등)**: `js/app.js`의 `const HOL={...}`에 `"2028-01-01":"신정",` 형식으로 추가
- **절차 추가**: `js/app.js`의 `const P=[...]`에 같은 형식으로 한 줄 추가
- 파일을 고친 뒤에는 `sw.js`의 `VERSION`을 `"v2"`처럼 올려 주세요 (설치한 사람에게 새 버전이 반영됨)

## 유의

업무용 참고 도구입니다. 법적 효력이 없으며 실제 기산일·휴일 적용·금액은 사건 기록과 법원 안내로 확인해야 합니다.
